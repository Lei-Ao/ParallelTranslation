本地 PDF 对照翻译工作台。接入自己的 AI 接口，在原文与译文之间同步阅读，并尽可能保留页面版式。界面名称为「页间 Parallel」，文档提供中英文版本。

## 功能

- **对照阅读**：原文与译文并排展示，支持连续翻页、双向同步滚动、段落定位、缩放及词句选择复制。
- **桌面启动**：Windows 下双击 `start.bat` 或 `start.vbs` 后驻留系统托盘，不会保留终端窗口；关闭浏览器不会停止服务，托盘菜单可打开工作台、重启、停止和退出。
- **版式排印**：保留页面尺寸和图形，在安全区域内排印译文，参考原文的字体样式、段间距与栏结构。
- **链接保留**：原文中的网页链接与文内跳转随译文重新定位，译文页面可直接点击；链接文字沿用原文颜色，换行链接的各段会作为一组同时高亮。
- **自带 AI**：支持 OpenAI 兼容的 Chat Completions 接口，也可配置自定义 HTTP JSON Agent。
- **上下文翻译**：携带前后段落、已完成译文、目标语言、术语表和翻译要求。
- **并发与恢复**：可调请求并发和同页批量翻译；支持暂停、失败重试及跳过已有译文。
- **修订与导出**：支持逐段编辑、重新翻译、导出对照 Markdown，以及自动保存独立译文 PDF。
- **全文视觉助读**。支持直接阅读、章节目录和逐节陪读。文章速读由同一个多模态模型结合完整原文、章节结构及全部页面图整体分析，提供研究问题、方法、结论和建议阅读路线。
- **引用上下文问答**。选中原文或译文后解释、加入引用或高亮，支持多段和跨页引用。结合完整段落、前后文及相关章节回答，图表与公式可进行区域视觉核查。
- **本地阅读笔记**。整条回答可收藏为独立笔记，保存提问、回答、公式、引用和视觉来源，支持查看、删除及 Markdown 导出。

> 项目针对文档的几何、字体及版式特征做通用判断。复杂区域可能保留原文并给出原因，不能保证所有 PDF 的每个区域都能完成翻译排版。

## 更新日志

### 2026-11-07 跨页段落、公式完整性与性能

- **跨页/跨栏段落**：自动识别同一自然段落在页末或栏末被切开的情况；译文页末片段按原文高度回填行距，减少大块空白。翻译时提示模型顺着上一片段续写、不重复已译出的词；原文没有省略号时禁止自行添加“……”并在必要时重试一次。
- **行内二维公式**：分式、上下标由多个提取块组成时，按整簇原始字形复刻（例如 `e^{−‖x‖/δ}`）；无法可靠复刻时保留整段原文并报告原因，不再输出 `e δ` 这类残缺公式。
- **排版性能**：清理排版链路中的重复整页提取和预检计算。14 页 / 339 段样本冷排版 6.14s → 4.82s（字体缓存预热），单页编辑 0.74s → 0.48s，单页 `typeset` 0.34s → 0.22s；排版报告逐字段一致，缓存版本 75。
- **阅读交互与批注**：原文、译文和段落视图均支持选词引用；新增多色高亮、跨页引用、批注汇总和本地笔记，保留直接阅读、文章速读和逐节陪读。
- **品牌与工程**：应用、托盘和浏览器标签页统一为「绿色书本 + 译向箭头」图标；新增跨页段落、图表、列表、选择层等模块及对应回归用例。
- **验证**：333 项 Python、80 项 JavaScript 用例及 Edge 浏览器 smoke 通过；两篇真实样本重新排版，译文汉字缺失、文字碰撞、字体、粗体、符号和链接检查为空。页末行距填充使 7 个续写段的首行间距比原文参考值少 0.2–0.6 pt，语料审计会将其列为 `spacing_errors`；这是为回收空白而主动调整行距的结果，不是文字碰撞。有限样本通过不代表所有论文的复杂区域均已适配。

### 2026-11-06 全文视觉助读、引用问答与本地笔记

- **整体速读与进度**。完整原文和全部页面图进入同一多模态上下文，正文按内容展开，取消速读总字数限制。界面显示页面准备数量、整体分析、上下文补读和局部核查阶段，支持停止、重试和刷新恢复。
- **图表与公式核查**。最多四轮补读或视觉核查，每轮最多12项操作。局部区域最高8倍渲染，单图限制为400万像素，并复用相同区域、版本及渲染参数的图像。最终回答阶段关闭工具调用，修复全文分析触发旧工具调用上限的问题。
- **独立引用问答 Skill**。按引用的真实位置补齐完整段落、相邻上下文和章节信息，再按问题查找术语定义、公式及图表编号。原文和译文引用均由服务端校验，译文 PDF 使用对应排版版本定位，映射有歧义时提供原文及译文页面供核对。
- **收藏与清理**。对话按论文保存在本地，支持删除单条回答和清空对话。收藏保存完整回答及来源快照，清空对话后可独立查看、定位和导出笔记，兼容已有会话和阅读小结。
- **连续文章与公式排版**。统一标题、段落、列表、表格、公式和编号来源。共享 Skill 约束中文枚举、数学定界符及 JSON 转义，修复 Markdown 改写 LaTeX 转义后出现红色公式错误的问题。
- **阅读交互**。提供仅原文、双语对照及仅译文视图，支持原文与译文的精确引用、多色高亮和显式译文编辑开关，侧栏适配桌面及窄屏。
- **可追溯的待核实事项**。将取材失败、视觉辨认困难和论文交代不足分别记录具体位置、来源及影响，修复局部临时提示进入全文报告的问题。模型容量、图片能力或页面准备失败会显示对应原因。

### 2026-11 版式与排印修复

本仓库基于上游项目 Lei-Ao/ParallelTranslation 改进，改进版位于 XIA-J-B/ParallelTranslation。此前版本共修复以下版式问题。[上游项目](https://github.com/Lei-Ao/ParallelTranslation) · [本仓库](https://github.com/XIA-J-B/ParallelTranslation)

1. **图表标签错位**：靠近图形的刻度、图例等独立标签从普通段落流中分离，按原文的中心轴、字号和基线原位排印，不再挤占正文或偏离图形。
2. **摘要粗体丢失**：混合了常规正文的长粗体标签不再把整段正文误设为粗体；真正全段加粗的正文仍保持源字重，摘要标题与正文的粗细正确区分。
3. **短正文被缩小**：因局部文本框偏紧而缩小的正文段落，可借用同栏下一段译文缩短后未用的源高度恢复原字号。
4. **作者信息不齐**：首页作者、单位和邮箱按完整信息区统一预排版，作者编号保留为上标，邮箱独立使用等宽字体，各行不再逐段下移错位。
5. **表题及跨行标题局部加粗丢失**：表号/图号之后的粗体标题映射到译文对应首句，跨行粗体标签（含行末断词）连续识别，且不再连带后续常规说明一起加粗。
6. **原文与译文悬停高亮对应不完整**：原文段落或公式的多个提取片段合并排版时保留同页成员关系，对照阅读按组双向悬停高亮与选中，不再只高亮最后几个词或公式一行。
7. **同一公式出现多个选中框**：合并公式组的所有成员共用一个外接边框和透明底色，每侧仅绘制一次，不再出现多个小框或底色叠加过深。
8. **小标题斜体丢失、被统一加粗**：斜体和字重独立依据原文字体标志确定，编号或标题结构不再触发统一加粗；中文按当前可嵌入字体族合成 12° 倾斜的斜体字面。
9. **标题独立排印**：标题与正文被提取到同一文本块时，按原文行几何识别结构分界并分别排印，恢复标题独立成行、居中及原有字号、字重、斜体与间距。
10. **公式编号随公式移动**：公式尾部标点和编号被提取进后续说明段落时，与原始公式一起按矢量内容整体移动，编号保留在公式右侧及原有相对位置。

排版缓存版本由 61 更新至 66：重新打开文档或点击「重新排版」即可生效，无需重新翻译，已保存译文、段落标识与原始 PDF 不变。回归覆盖合成单栏/双栏、不同页面宽度、0/90/180/270 度旋转及本地论文样本；复杂版式仍可能保留原文并提示原因。

## 快速开始

### Windows

1. 安装 **Python 3.10 或更新版本**，确保终端可以运行 `python`。
2. 克隆仓库，或通过 GitHub 的 **Code → Download ZIP** 下载并解压。
3. 双击项目根目录的 **`start.bat`**。首次启动会创建 `.venv` 并安装固定版本依赖（此时会短暂显示终端窗口）。
4. 之后双击 `start.bat` 或 **`start.vbs`** 即可，不会保留终端窗口：程序在系统托盘显示「页间 Parallel」图标，并自动打开 <http://127.0.0.1:8765>。

```powershell
git clone https://github.com/XIA-J-B/ParallelTranslation.git
cd ParallelTranslation
.\start.bat
```

托盘图标双击打开工作台；右键菜单可以「打开工作台」「重新启动服务」「启动服务 / 停止服务」或「停止并退出」。关闭浏览器不会停止服务；需要完全停止时从托盘菜单选择「停止并退出」，也可以双击 **`stop.bat`** 强制停止。服务日志位于 `tmp/parallel.log`。再次启动已运行的实例只会打开工作台，不会重复启动服务。

托盘使用绿色双页书本与译向箭头图标，悬停显示「页间 Parallel」。如果 Windows 将它收进隐藏区域，可点击任务栏右下角的 `⌃` 查看，再将图标拖到任务栏常驻显示。更新图标后，先退出旧托盘程序，再双击 `start.vbs`；浏览器标签页也使用同一图标。

不要直接打开 `static/index.html`；PDF 解析、译文保存与接口调用需要本机后端服务。当前测试环境为 Windows / Python 3.12。

### 手动安装与启动

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe launch.py
```

macOS / Linux 可使用手动启动方式；这些系统的完整阅读及字体效果尚未验证：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8765
```

`requirements-lock.txt` 用于安装已固定的依赖版本；`requirements.txt` 记录允许的版本范围。运行应用不需要 Node.js，Node.js 仅用于前端开发检查。

## 配置 AI 接口

打开「Agent 设置」，选择接口类型。

### OpenAI 兼容接口

- **Base URL**：填写服务商的 API 地址。程序会追加 `/chat/completions`，也支持填写完整端点。
- **API Key**：填写自己的密钥；无需认证的本机服务可以留空。
- **模型名称**：按服务商实际提供的模型 ID 填写，项目不预设可用模型。
- **思考强度**：控制 OpenAI 兼容接口的思考模式；「服务端默认」不发送任何相关参数，保持服务商自己的默认行为。选「关闭思考」发送 `thinking: {"type": "disabled"}`，选低 / 中 / 高 / 最高发送对应 `reasoning_effort`。DeepSeek 默认开启思考且强度为高，关闭可节省时间与费用，调高会变慢并可能顶到请求超时。自定义接口不受此项影响，由请求模板决定。
- **测试连接**：发送一次真实模型请求，可能产生接口费用。

界面当前预填的 Base URL 是 `https://api.apigoto.com/v1`，可按需更换。该预填地址不代表服务可用性或质量保证；集成测试使用模拟接口。

### 自定义 HTTP JSON Agent

填写完整 POST 地址、JSON 请求模板和译文响应字段路径，例如：

```json
{
  "input": "{{prompt}}",
  "model": "{{model}}",
  "metadata": { "target_language": "{{target}}" }
}
```

支持 `{{prompt}}`、`{{text}}`、`{{target}}`、`{{model}}`。响应字段路径可填写 `data.text` 或 `choices.0.message.content`。密钥通过 `Authorization: Bearer ...` 发送。

目前仅支持一次请求完成的非流式 JSON 响应；SSE、异步轮询及特殊认证需另行适配。

## 使用流程

1. 在首页选择目标语言，按需填写「术语与要求」。
2. 导入文字型 PDF。程序解析后自动翻译，首页显示进度；全文译完并完成排版后进入阅读界面。
3. 翻译期间可暂停；失败后点击「继续翻译」，跳过已有当前语言译文。
4. 两侧单击段落可同步定位，单击空白处取消选择。拖选文字可解释、引用或高亮，需要编辑译文时在菜单开启「译文编辑」后双击对应段落。也可切换「段落」视图。
5. 在菜单中调整语言、并发、批量段数、同步滚动与阅读模式，或重新排版、下载 PDF、导出对照 Markdown。

默认并发 **3** 个请求，最高 **12** 个；OpenAI 兼容接口默认每次合并同页最多 **3** 段，可选 1 / 3 / 5 段。自定义接口使用单段请求。接口临时错误最多自动重试两次，重试可能产生额外费用。

### 论文助手与 AI 助读

文档库中点击每篇文档下方的「直接阅读」，或在导入前勾选「导入后直接阅读（不自动翻译）」，即可跳过全文翻译等待。原有的导入后翻译流程仍保留。未译区域显示完整原文及未译提示。

进入阅读器后点击右上角「论文助手」，可使用「文章速读」「逐节陪读」及「对话／笔记／批注」标签。原文与译文支持并排或单侧显示，窄窗口切换论文与助读内容。打开侧栏和切换标签本身无需调用模型。

- **文章速读**。点击按钮或输入“分析整篇论文，生成文章速读并给出建议阅读路线”即可启动完整原文与全部页面图的整体分析，需要支持图片输入和工具调用的多模态模型。输入超过接口容量时可调整模型或接口后重试。
- **逐节陪读与引用问答**。逐节解释当前阅读单元，或选中一处及多处原文／译文提问。引用问答先直接解答，再结合真实上下文解释依据，必要时补读相关章节和查看图表公式。
- **来源与待核实事项**。正文使用紧凑编号，文末提供去重来源，点击可精确定位。视觉记录默认折叠。待核实事项列出具体位置、原因及影响，论文陈述和辅助解释分别标注。
- **对话、笔记与批注**。回答可收藏、查看或删除，笔记可独立导出 Markdown；「批注」标签汇总当前文档的本地高亮、待发送引用和已发送引用，可点击回跳或删除高亮。清空对话前会确认并停止当前任务，阅读位置和阅读单元进度继续保存。
- **历史分析**。更多菜单保留旧版目录、概览、精读和问答入口，旧结果可继续查看，具体行为见开发说明。[论文助手开发说明](docs/reading-assistant.zh-CN.md)

AI 助读会按所选模式将原文、页面或区域图像、问题和相关对话上下文发送到当前配置的模型接口，可能产生费用。速读会提供完整原文与全部页面图。对话及任务记录保存在 `.data/<文档ID>/reading.json`，收藏笔记保存在同目录的 `reading-notes.json`，历史分析记录位于 `analysis.json`。这些文件使用配置摘要标识模型，密钥存于浏览器设置。后台分析在关闭侧栏或刷新页面后继续运行，关闭本地服务会中断任务，重启后可手动重试。

AI 助读回答可收藏为本地笔记，在「笔记」标签查看、删除或导出 Markdown。普通对话保留到手动删除或清空，收藏笔记独立保存。使用方式见 [Skill 原生论文陪读说明](docs/skill-reading.zh-CN.md)。

扫描页通过图像参与速读，文字选区需要可靠的文字层。取材失败或视觉核查后仍无法确认的内容会列出具体疑点及影响。助读的使用与验证范围见陪读说明。[Skill 原生论文陪读说明](docs/skill-reading.zh-CN.md)

暂停会停止安排新请求，已发送请求会继续返回并保存。翻译期间请保持页面打开；刷新后可以从文档库重新打开并继续。

## 保存与隐私

| 内容 | 保存位置或行为 |
| --- | --- |
| 原始 PDF、提取文本、译文与布局缓存 | `.data/<文档 ID>/` |
| 完成的独立译文 PDF | 项目根目录下的 `output/pdf/` |
| Agent 配置、API Key、语言及术语设置 | 当前浏览器的 localStorage |
| 阅读会话与笔记 | 文档目录内的 `reading.json`、`reading-notes.json`；阅读高亮保存在当前浏览器 |
| 发给 AI 服务的内容 | 翻译时发送段落、上下文及翻译要求；助读时按所选功能发送原文、页面或区域图像、问题及相关对话 |

- PDF 二进制文件不会上传给配置的翻译接口，但相关文本会发送给该服务。
- 浏览器中的密钥存储**未加密**；输入框隐藏仅遮挡显示。可使用「清除已保存密钥」移除密钥。
- 不要把密钥写入 URL、请求模板、源码或提交记录。
- 完整翻译并排版成功后，成品 PDF 自动保存到项目根目录下的 `output/pdf/` 文件夹（首次保存时自动创建），可脱离应用直接打开。保存成功或重新打开文档时，不再弹出保存路径；保存失败仍会提示。排版仍可能包含保留原文的区域，请查看排版提示。
- 每份文档当前仅保存一套译文；切换语言并重新翻译会逐段替换原有译文，需要旧版本时请先导出。
- 备份数据可复制整个 `.data/`。仓库及源码包不包含个人文档、译文、密钥、缓存、虚拟环境或本机开发截图。

本项目是单用户本地工具，默认只监听 `127.0.0.1`，不适合直接部署为公开的多用户服务。

## 支持范围与限制

- 支持 **1–300 页、最大 50 MB** 的 PDF。
- 扫描件翻译和文字选区需要 OCR 文字层；全文视觉速读也可读取扫描页的图像。
- 多栏、旋转、标题、作者信息、行内符号、首字下沉和参考文献等使用版式规则处理，复杂文档仍可能存在提取或排版误差。
- 被提取成多个文本块的封面标题会合并为一个标题组，统一使用原文标题的字号与源字重排印；作者编号按原文保留为上标，不依赖编号与姓名的连接方式。旋转封面和不在首页的标题仍按逐块方式处理。
- 跨页、含未加引号专著题名或编号不连续等无法重建为完整条目的参考文献，会整段保留原文并在排版提示中说明，避免同一文献条目中英文混排或译文覆盖相邻条目；标题仍正常翻译。无法识别编号的续页按普通文本处理。
- 原文中的网页链接和文内跳转（引用、图表、目录）会重新锚定到译文对应位置；译文改写导致锚文本无法定位时，外部链接不再可点并在排版提示中说明，文内跳转按原位置保留。链接文字颜色沿用原文，链接下划线等装饰不重建。阅读器只为可可靠定位或整块锚定的链接显示点击层；按原位置保留的文内跳转仍存在于导出的 PDF 中。
- 模型有时会把同一段译文返回成多行；排版和阅读视图会把源段落内部的软换行合并为一个段落（列表、术语表等多行结构除外），编辑框和已保存译文保持原样。
- 独立公式、复杂表格、竖排文字或无法安全容纳的区域可能保留完整原文；表格通常只翻译表题和表注。
- 图片内的文字不进行 OCR 或替换。翻译进度表示已生成的段落译文比例，不代表所有区域均已替换进 PDF。
- 原文以渲染页面显示，支持段落交互、文字选区和本地高亮。全文搜索与 PDF 内嵌批注仍需其他工具。
- 中文排印会优先查找本机 Noto Serif SC、等线字体；没有可用字体时使用内置回退。不同系统的字体效果可能不同。
- 生成内容和保留区域应人工审核，特别是公式、表格、关键数字和专业术语。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/app.js

```

测试使用临时 PDF 与模拟接口，不消耗真实 AI 服务额度。针对本机已有译文的可选排版检查：

```powershell
.\.venv\Scripts\python.exe tests/audit_corpus_layout.py
```

该检查在 `tmp/source-layout-audit/` 写入报告和预览。个人论文样本不随仓库分发；新克隆的项目没有这些样本。排版实现和回归边界见 [开发与排版说明](docs/development.zh-CN.md)，通用适配要求见 [AGENTS.md](AGENTS.md)。

```text
app.py                  FastAPI、文档保存、Agent 适配与导出
```

## Skill 原生论文陪读

阅读论文时点击「论文助手」，选择「文章速读」或「逐节陪读」。左侧目录、中间双语论文、右侧对话独立滚动，输入框常驻底部；原文支持精确选句、追加多段引用并回跳定位。应用直接加载内置 `paper-reading-guide` 和版本化阅读工作流，检查取材、输出结构与引用，不回退为无约束回答。旧会话保留原版本，可在更多菜单归档后新建。模型接口需支持工具调用和图片输入，可先运行更多菜单中的「测试模型能力」。

升级后请在托盘菜单重新启动服务并刷新页面。具体使用、自定义接口协议、数据兼容性和验证方式见 [Skill 陪读说明](docs/skill-reading.zh-CN.md)。上游来源、MIT 许可及文件哈希保存在 `skills/paper-reading-guide/`。
