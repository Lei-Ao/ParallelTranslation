本地 PDF 对照翻译工作台。接入自己的 AI 接口，在原文与译文之间同步阅读，并尽可能保留页面版式。界面名称为「页间 Parallel」，文档提供中英文版本。

## 功能

- **对照阅读**：原文与译文并排展示，支持连续翻页、双向同步滚动、段落定位、缩放及词句选择复制。
- **桌面启动**：Windows 下双击 `start.bat` 或 `start.vbs` 后驻留系统托盘，不会保留终端窗口；关闭浏览器不会停止服务，托盘菜单可打开工作台、重启、停止和退出。
- **版式排印**：保留页面尺寸和图形，在安全区域内排印译文，参考原文的字体样式、段间距与栏结构。
- **链接保留**：原文中的网页链接与文内跳转随译文重新定位，译文页面可直接点击；链接文字沿用原文颜色，换行链接的各段会作为一组同时高亮。
- **自带 AI**：支持 OpenAI 兼容的 Chat Completions 接口，也可配置自定义 HTTP JSON Agent。
- **上下文翻译**：携带前后段落、已完成译文、目标语言、术语表和翻译要求。
- **并发与恢复**：可调请求并发和同页批量翻译；支持暂停、失败重试及跳过已有译文。
- **修订与导出**：支持逐段编辑、重新翻译、导出对照 Markdown，以及自动保存独立译文 PDF。
- **论文助手**：可直接打开原文，按章节陪读，选中原文或译文提问，并把回答、引用和公式收藏为本地笔记。

> 项目针对文档的几何、字体及版式特征做通用判断。复杂区域可能保留原文并给出原因，不能保证所有 PDF 的每个区域都能完成翻译排版。

## 更新日志

### 2026-11-08 统一视觉 API、文档结构、直接翻译与文档库管理

本次更新保留速度优先的直接翻译，并将版面识别和排版视觉验收接入同一翻译 API。更新后请**重启本机服务并刷新页面**。

**翻译流程与人工术语**

- 统一直接翻译，保留前后文、已有译文、人工术语、翻译要求、格式检查与有限失败重试。已移除自动术语准备及“初译 → 模型审校 → 修订 → 复核”，不再自动改写历史译文。
- 默认每批最多 **3 段、3 个并发请求**；每批可选 1／3／5 段或自动，并发与批量独立设置。旧浏览器曾保存的 5 段首次升级时一次性迁移到 3，之后主动选择 5 段仍正常保存；自定义 HTTP 接口仍逐段翻译。
- 通用“术语与要求”继续保留；新增文档级人工词表，支持添加、编辑、禁用及 CSV 导入导出。文档人工词条优先于通用词表，历史自动词条不参与新请求。
- 旧审校草稿、建议和任务记录仍可查看；旧执行接口返回 HTTP 410。手动接受历史候选会检查期间是否有新的编辑，不会恢复模型审校流程。

**文档库与阅读数据**

- 论文可重命名，原文、译文、段落 ID、笔记引用与阅读定位保持兼容。
- 删除须确认，应用内文档移入 `.data/.trash`，保留原始导入文件和已有 `output/pdf` 导出。正在翻译、排版或由论文助手处理的文档禁止改名和删除；删除当前文档后同步清理阅读界面与列表缓存。

**翻译与排版性能**

- 复用 HTTP 连接，批次部分成功时立即保存有效译文，只补发缺失或不合法段落；识别出的跨页／跨栏续句等待前段译文，迟到结果不能覆盖人工编辑。
- 可选自动组批以约 1,200 原文字符为软预算，最多 12 个同页短块；1,000 字符及以上长块单独请求，正文与参考文献分组。自动并发从 3 开始，连续 12 次干净请求后逐步增加至 6，限流或连续超时降低并发，并尊重 `Retry-After`。固定并发最高仍为 12。
- 默认提前排版已完成页面，最终核对最新缓存、合并页面并恢复链接。按页字体及布局缓存减少重复工作；修复公式后正文上移侵入完整公式文字框的问题。
- 阅读菜单可导出耗时报告；本地数字诊断记录请求、重试、排版和缓存情况，不记录密钥、提示词或译文。历史 23 块的小样本速度对照不包含本次新增视觉 API 的耗时，不能视为当前全流程或所有论文的性能承诺。

**文档结构、公式与样式**

- 借鉴 BabelDOC 的中间表示和保护机制，提取、翻译及排版共用页面、字符、段落、局部样式、原始公式字形和图形障碍信息；保持原始段落 ID，源结构与译文关系分别保存。
- 公式通过无碰撞占位符参与翻译，逐项校验身份和次数；局部样式使用配对标记。正式译文、编辑框与 Markdown 均为恢复后的纯文本，人工编辑使旧结构对应关系失效。
- 保留正文基础字体及字号，局部粗体、斜体、颜色、上标和符号级字体回退独立处理；段首标签或粗体变量不会因此把整段正文变粗。
- 历史译文仅在可靠对应时恢复公式，支持下标和点导数等价写法及数量一致的重复公式；无法安全对应或排版的区域完整保留原文并报告原因，不自动重译。
- 扫描图像配隐藏 OCR 层的页面完整保留，避免在扫描内容上叠印译文。此回退不代表已完成扫描件翻译或 OCR 重建。

**统一 API 的版面识别与视觉验收**

- 默认当前翻译模型支持图片；版面识别、文字翻译及排版视觉验收使用相同 API 地址、模型、密钥和思考设置。没有本地识别模型或新增运行依赖，本机负责 PDF 解析、渲染、几何校验和生成。
- 版面识别发送原文页图片，识别结果还需与文字、字体、绘图和图片位置交叉校验；模型边界框本身不能授权擦除内容。
- 视觉验收发送原文与译文页图片，检查漏字、截断、重叠、公式变化、图表遮挡、异常留白和样式变化，不进行译文措辞审校。图片及相关文本会发送给配置的服务，可能增加请求费用和耗时。
- 新前端区分“通过／发现问题／未完成”：仅通过后自动更新导出 PDF；发现问题或接口失败时保留候选预览与明确标记的候选下载，不覆盖之前的自动导出文件。模型不可用不会记为验收通过。
- 识别与验收按页缓存；原文、API 设置、提示协议、译文或输出变化会使相关缓存失效，重复排版不重复发送有效缓存中的页面。自定义 HTTP 视觉模板需使用结构化 `{{messages}}` 或 `{{images}}`。

**升级兼容与验证范围**

- 最终排版缓存版本 **79**、源结构版本 **5**、译文结构及视觉验收版本 **1**。旧缓存保留但不误用；已有文档按需补建结构，普通打开阅读不强制重新分析全文。旧客户端未提供 `agent` 时保留几何排版兼容，但明确标记未进行视觉验收。
- Windows／Python 3.12 下 **380 项 Python、95 项 JavaScript** 测试及三类隔离浏览器验收通过。API 通过 HTTP 模拟服务验证多模态图片、认证、响应校验、缓存和失败保护；**尚未调用用户真实翻译 API 验证视觉判断质量**。
- 按原始 PDF 摘要去重检查 **13 份输入／20 页**：1 篇已有完整译文的 8 页论文、4 份单页参考 PDF、8 份单双栏与四种旋转合成页。参考样本采用原文作为译文，合成页使用确定性译文，不能等同多篇真实模型翻译验收。
- 完整论文的已放置中文缺失、碰撞、间距、字体突变、正文误加粗、符号和链接检查无新增报告项；5 个历史译文块因公式不能可靠对应而新增保留。**保留原文不计为适配成功，也不承诺所有论文均已验证或首次处理更快。**

## 快速开始

### Windows

1. 安装 **Python 3.10 或更新版本**，确保终端可以运行 `python`。
2. 克隆仓库，或通过 GitHub 的 **Code → Download ZIP** 下载并解压。
3. 双击项目根目录的 **`start.bat`**。首次启动会创建 `.venv` 并安装固定版本依赖（此时会短暂显示终端窗口）。
4. 之后双击 `start.bat` 或 **`start.vbs`** 即可，不会保留终端窗口：程序在系统托盘显示「页间 Parallel」图标，并自动打开 <http://127.0.0.1:8765>。

```powershell
git clone https://github.com/Lei-Ao/ParallelTranslation.git
cd ParallelTranslation
.\start.bat
```

托盘图标双击打开工作台；右键菜单可以「打开工作台」「重新启动服务」「启动服务 / 停止服务」或「停止并退出」。关闭浏览器不会停止服务；需要完全停止时从托盘菜单选择「停止并退出」，也可以双击 **`stop.bat`** 强制停止。服务日志位于 `tmp/parallel.log`。再次启动已运行的实例只会打开工作台，不会重复启动服务。

托盘使用绿色双页图标，悬停显示「页间 Parallel」。如果 Windows 将它收进隐藏区域，可点击任务栏右下角的 `⌃` 查看，再将图标拖到任务栏常驻显示。更新图标后，先退出旧托盘程序，再双击 `start.vbs`；浏览器标签页也使用同一图标。

不要直接打开 `static/index.html`；PDF 解析、译文保存与接口调用需要本机后端服务。当前测试环境为 Windows / Python 3.12。

### 手动安装与启动

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe launch.py
```

macOS / Linux 可使用手动启动方式；这些系统的完整阅读及字体效果尚未验证：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8765
```

`requirements-lock.txt` 用于安装已固定的依赖版本；`requirements.txt` 记录允许的版本范围。运行应用不需要 Node.js，Node.js 仅用于前端开发检查。

## 配置 AI 接口

打开「Agent 设置」，选择接口类型。

### OpenAI 兼容接口

- **Base URL**：填写服务商的 API 地址。程序会追加 `/chat/completions`，也支持填写完整端点。
- **API Key**：填写自己的密钥；无需认证的本机服务可以留空。
- **模型名称**：按服务商实际提供的模型 ID 填写，项目不预设可用模型。
- **思考强度**：默认沿用服务端设置，不添加思考参数；可按服务商支持情况选择关闭或调整强度。不支持该选项的接口请改回「服务端默认」。自定义接口由请求模板控制。
- **测试连接**：发送一次真实模型请求，可能产生接口费用。

界面当前预填的 Base URL 是 `https://api.apigoto.com/v1`，可按需更换。该预填地址不代表服务可用性或质量保证；集成测试使用模拟接口。

### 自定义 HTTP JSON Agent

填写完整 POST 地址、JSON 请求模板和译文响应字段路径，例如：

```json
{
  "input": "{{prompt}}",
  "model": "{{model}}",
  "metadata": { "target_language": "{{target}}" }
}
```

支持 `{{prompt}}`、`{{text}}`、`{{target}}`、`{{model}}`。响应字段路径可填写 `data.text` 或 `choices.0.message.content`。密钥通过 `Authorization: Bearer ...` 发送。

视觉版面识别与验收需在自定义模板中提供 `{{messages}}` 或 `{{images}}` 结构化变量。

目前仅支持一次请求完成的非流式 JSON 响应；SSE、异步轮询及特殊认证需另行适配。

## 使用流程

左侧文档库每篇论文下方提供“重命名”和“删除”。重命名只修改显示名称，保留原文、译文和段落定位。删除需要确认，会将应用内该论文的文件移入 `.data/.trash` 回收目录并从列表移除；原始导入文件及 `output/pdf` 中的导出文件不删除。正在翻译、排版或阅读助手处理期间请等待完成再操作。

当前统一采用**直接翻译**，已移除自动术语准备和模型审校、修订、复核。保留手动“术语与要求”，默认每批最多 3 段、3 个并发请求，已有选择继续保留。“文档术语与历史记录”可编辑人工词表及查看旧记录。旧审校任务不能重新启动；已有译文不会自动改写。更新后需重启服务并刷新页面，详见[直接翻译说明](docs/translation-quality.zh-CN.md)。

1. 在首页选择目标语言，按需填写「术语与要求」。
2. 导入文字型 PDF。程序解析后自动翻译，首页显示进度；全文译完并完成排版后进入阅读界面。
3. 翻译期间可暂停；失败后点击「继续翻译」，跳过已有当前语言译文。
4. 两侧单击段落可同步定位，单击空白处取消段落选择。拖动选择词句后按 Ctrl+C 复制，默认双击选词。编辑时，在菜单中打开「开启译文编辑」，再双击译文段落。
5. 在菜单中调整语言、并发、批量段数、同步滚动与阅读模式，或重新排版、下载 PDF、导出对照 Markdown。

默认并发 **3** 个请求，最高 **12** 个；OpenAI 兼容接口默认每次合并同页最多 **3** 段，可选 1 / 3 / 5 段。自定义接口使用单段请求。接口临时错误最多自动重试两次，重试可能产生额外费用。

阅读菜单新增可选的「自动」组批与并发，已有固定档位设置继续保留。自动组批最多合并 12 个短块，以约 1,200 原文字符为软预算，1,000 字符及以上的长块单独请求；正文与参考文献分开，识别出的续句等待前一片段译文。自动并发从 3 开始，连续 12 次干净请求后增加，最高 6；限流或连续超时会降低并发，并遵守服务端等待时间。模型、思考设置、术语和翻译要求不变。

默认开启「翻译时提前排版已完成页面」，也可在阅读菜单关闭。最终导出仍核对页面缓存并统一恢复链接。菜单中的「导出最近一次耗时报告」可查看翻译、最终等待、请求、重试和缓存情况；后端数字诊断保存在 `tmp/performance.jsonl`，不记录密钥、提示词或译文正文。实现、实测范围与限制见 [性能验证说明](docs/performance.zh-CN.md)。

暂停会停止安排新请求，已发送请求会继续返回并保存。翻译期间请保持页面打开；刷新后可以从文档库重新打开并继续。

### 直接阅读与论文助手

导入前勾选「导入后直接阅读」，或在文档库点击「直接阅读」，即可先看原文。进入阅读器后打开「论文助手」，可在仅原文、双语对照和仅译文之间切换。

- 想了解整篇论文时，选择「文章速读」。模型会收到全文、章节目录和每一页的图像。请使用支持图片输入、工具调用且容量足够的接口。
- 想弄清某个公式或表述时，拖选原文或译文后点击「解释」或「引用」。可追加多处选区、跨页提问、框选图表，也可从回答中的来源回到对应位置。
- 想留存回答时，点击「收藏为笔记」。在「笔记」标签可重新查看引用并导出 Markdown，清空对话后仍可查看已收藏的笔记。

打开侧栏和浏览目录无需调用模型。发起助读后会使用当前配置的模型接口，可能产生费用。更新后从托盘重新启动服务并刷新页面即可使用。自定义接口协议、容量限制及历史记录兼容性见 [论文陪读说明](docs/skill-reading.zh-CN.md)。

## 保存与隐私

| 内容 | 保存位置或行为 |
| --- | --- |
| 原始 PDF、提取文本、译文与布局缓存 | `.data/<文档 ID>/` |
| 完成的独立译文 PDF | 项目根目录下的 `output/pdf/` |
| Agent 配置、API Key、语言及术语设置 | 当前浏览器的 localStorage |
| 阅读会话与笔记 | 文档目录内的 `reading.json`、`reading-notes.json`；阅读高亮保存在当前浏览器 |
| 发给 AI 服务的内容 | 翻译时发送段落、上下文及翻译要求；版面识别与视觉验收发送原文／译文页图片及相关文本；助读时按所选功能发送原文、页面或区域图像、问题及相关对话 |

- PDF 二进制文件不会上传给配置的翻译接口；相关文本，以及版面识别和视觉验收所需的页面图片会发送给该服务。
- 浏览器中的密钥存储**未加密**；输入框隐藏仅遮挡显示。可使用「清除已保存密钥」移除密钥。
- 不要把密钥写入 URL、请求模板、源码或提交记录。
- 完整翻译、排版并通过视觉验收后，成品 PDF 自动保存到项目根目录下的 `output/pdf/` 文件夹（首次保存时自动创建），可脱离应用直接打开。保存成功或重新打开文档时，不再弹出保存路径；保存失败仍会提示。排版仍可能包含保留原文的区域，请查看排版提示。
- 每份文档当前仅保存一套译文；切换语言并重新翻译会逐段替换原有译文，需要旧版本时请先导出。
- 备份数据可复制整个 `.data/`。仓库及源码包不包含个人文档、译文、密钥、缓存、虚拟环境或本机开发截图。

本项目是单用户本地工具，默认只监听 `127.0.0.1`，不适合直接部署为公开的多用户服务。

## 支持范围与限制

- 支持 **1–300 页、最大 50 MB** 的 PDF。
- 文字选区依赖可提取文字或 OCR 文字层；扫描图像配隐藏 OCR 层的页面本轮完整保留，未实现扫描件重建。全文视觉速读仍可读取扫描页图像。
- 多栏、旋转、标题、作者信息、行内符号、首字下沉和参考文献等使用版式规则处理，复杂文档仍可能存在提取或排版误差。
- 被提取成多个文本块的封面标题会合并为一个标题组，统一使用原文标题的字号与源字重排印；作者编号按原文保留为上标，不依赖编号与姓名的连接方式。旋转封面和不在首页的标题仍按逐块方式处理。
- 跨页、含未加引号专著题名或编号不连续等无法重建为完整条目的参考文献，会整段保留原文并在排版提示中说明，避免同一文献条目中英文混排或译文覆盖相邻条目；标题仍正常翻译。无法识别编号的续页按普通文本处理。
- 原文中的网页链接和文内跳转（引用、图表、目录）会重新锚定到译文对应位置；译文改写导致锚文本无法定位时，外部链接不再可点并在排版提示中说明，文内跳转按原位置保留。链接文字颜色沿用原文，链接下划线等装饰不重建。阅读器只为可可靠定位或整块锚定的链接显示点击层；按原位置保留的文内跳转仍存在于导出的 PDF 中。
- 模型有时会把同一段译文返回成多行；排版和阅读视图会把源段落内部的软换行合并为一个段落（列表、术语表等多行结构除外），编辑框和已保存译文保持原样。
- 独立公式、复杂表格、竖排文字或无法安全容纳的区域可能保留完整原文；表格通常只翻译表题和表注。
- 图片内的文字不进行 OCR 或替换。翻译进度表示已生成的段落译文比例，不代表所有区域均已替换进 PDF。
- 根据可见绘图、图片和图注识别图形区域。能按源行逐项对应且通过空间预检的独立标签，保持源中心轴、基线和字号翻译；复杂流程图、对应不明或含无法可靠重建的链接/上标的标签完整保留原文并提示原因，图注单独翻译。缺少可靠图形证据的纯文字图示可能无法识别。
- 原文与排版后的译文以渲染页面显示，文字层按可见页按需加载，支持自由选择和复制 PDF 中可提取的文字。图片、扫描件或缺少有效字符映射的字形无法据此恢复文字；跨行复制可能保留 PDF 的换行，复杂公式的复制结果取决于 PDF 的文字编码。暂不支持全文搜索或 PDF 内嵌批注。
- 中文排印会优先查找本机 Noto Serif SC、等线字体；没有可用字体时使用内置回退。不同系统的字体效果可能不同。
- 生成内容和保留区域应人工审核，特别是公式、表格、关键数字和专业术语。

## 开发

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/app.js
node --test (Get-ChildItem tests/test_*.js).FullName
```

测试使用临时 PDF 与模拟接口，不消耗真实 AI 服务额度。针对本机已有译文的可选排版检查：

```powershell
.\.venv\Scripts\python.exe tests/audit_corpus_layout.py
```

该检查在 `tmp/source-layout-audit/` 写入报告和预览。个人论文样本不随仓库分发；新克隆的项目没有这些样本。排版实现和回归边界见 [开发与排版说明](docs/development.zh-CN.md)，通用适配要求见 [AGENTS.md](AGENTS.md)。

```text
app.py                  FastAPI、文档保存、Agent 适配与导出
launch.py               本机服务启动与浏览器打开
start.bat / start.vbs   Windows 一键启动（隐藏终端，托盘控制）
stop.bat                停止本机服务与托盘
tray.ps1                Windows 托盘菜单（打开/重启/停止/退出）
pdf_text.py             首字下沉与完整单词恢复
pdf_selection.py        阅读器文字选择层的字符几何提取
pdf_structures.py       独立图表标签与作者网格的原位排印
pdf_layout.py           PDF 排版、图表避让与按页缓存
pdf_flow.py             分栏重排与公式区域移动
pdf_figures.py          图形区域识别与图内文字保护
pdf_lists.py            列表结构恢复、编号与悬挂缩进
pdf_typography.py       字体子集、字重与符号回退
pdf_references.py       参考文献恢复、题名翻译与排版
static/                 无构建依赖的 HTML、CSS、JavaScript
tests/                  Python / JavaScript 回归测试
docs/                   实现与回归说明
```

提交问题时请说明系统、Python 版本和复现步骤，并提供有权分享的最小 PDF 样本。请勿提交密钥或私人文档。
