# Skill 原生论文陪读

在论文阅读器点击「论文助手」→「文章速读」或「逐节陪读」。首次创建会话时加载工程内 `skills/paper-reading-guide` 的根版本、独立 `skills/reading-adapter.md` 及 `skills/reading-workflows`，保存文件内容快照和版本哈希。速读和引用问答在恢复会话后加载当前应用工作流规则，并在新回答中记录实际规则版本。其他阅读方式继续使用已存快照，更新这些规则后可归档旧会话并创建新版会话。没有可核实的上游提交号，因此只记录来源、导入日期和文件 SHA-256。

## 使用

- 默认双语对照，顶部切换仅原文、原文译文或仅译文。左目录224px，右助手默认400px、可调320—640px；小于1440px默认折叠目录，小于1040px切换论文／对话，不覆盖正文。对话独立滚动、输入区固定底部。
- 文章速读由同一个多模态模型结合完整原文、完整章节结构和全部页面图整体分析，再按研究问题、主要做法、核心结论和建议阅读路线输出，正文不限字数。扫描页通过页面图参与阅读。进度显示页面图准备数量、整体分析和局部核查阶段，刷新后恢复任务状态。
- 输入框直接提出分析整篇论文、通读全文或生成文章速读等明确请求时，也会进入全文速读。最多四轮局部视觉补看，每轮最多12个区域；最终回答阶段关闭工具调用。完整输入超出模型或接口容量时会提示调整后重试。局部区域采用最高8倍渲染、单图400万像素预算，视觉记录默认折叠。
- 拖选原文文字后使用「解释」或「加入引用」。可追加多段／跨页引用、单独移除，发送后随消息保存。后端重建引用文字，不能用客户端伪造内容；点击消息中的引用回到精确原文区域。译文仍按段落定位，不承诺句子级对齐。
- 显式引用会触发独立 `citation` Skill。后端依据每条引用的位置取得完整段落、前后文和章节信息，结合页面几何补充同栏上下文，按问题检索定义、公式及图表编号。补读和视觉查看最多四轮，每轮最多12项；材料在同一上下文中持续补充。回答先直接解答，再解释上下文与依据。译文PDF引用按对应版本的排版位置关联原文，定位有歧义时补充原文与译文页面。
- 待核实事项使用 `issues` 记录类别、页码、来源ID、具体疑点和影响，区分取材失败、视觉辨认困难、论文交代不足。后端检查实际来源和取材失败记录，旧 `missing` 数据兼容展示。界面执行进度独立于模型阅读材料。
- 点选段落后提问，或点击「框选图表」在原文页拖动框选。区域问题直接附带实际图像；「看当前页」用于图表、公式或扫描页。
- 「逐节陪读」讲解当前单元；回答后的「继续下一节」标记当前单元完成并前进，「跳过」只改变进度。原文滚动位置和陪读位置分别保存。
- 「生成新版本小结」要求模型读取上游模板和提问清单，并调用保存工具。小结以新的 UUID 文件保存在文档目录的 `reading-notes/` 中，可下载 Markdown，不覆盖旧版。
- 每条回答可「收藏为笔记」或「删除回答」。收藏保存整条回答、提问、公式、引用及原文定位快照，重复点击可查看已有笔记。在「笔记」标签按论文查看、删除或导出 Markdown，已有阅读小结也会出现在列表中。
- 普通对话在本地保留到手动清理。更多菜单中的「清空对话」会停止当前分析并清理对话、派生记忆和任务上下文，阅读位置与阅读单元进度继续保存。收藏笔记独立保存，删除原回答或清空对话后仍可查看来源与图片。分析运行期间可收藏已有回答，单条删除需要先等待或停止分析。
- 回答和笔记采用连续文章排版。正文按结构化栏目渲染，来源使用紧凑编号并在文末集中列出，材料缺口单独展示。标题、段落、列表、表格和公式使用统一样式；长公式和宽表格在各自区域横向滚动。排版规范来自 `skills/reading-workflows/formatting.md`，已有会话的新回答同样应用并记录版本。
- 「历史分析」继续查看原有目录、概览、段落解释和问答。新陪读不会迁移或删除 `analysis.json`。
- 旧版 Skill 会话可使用「归档并新建会话」升级，归档文件为 `reading-archive-<session_id>.json`，已有笔记可继续从本篇论文的笔记列表查看。

## 模型接口

统一使用当前 Agent 配置。OpenAI 兼容模式需要支持 `tools`、`tool_calls` 和 `image_url` 消息。点击「测试模型能力」会要求模型获取结构、渲染第一页并描述它；实际执行请求不等于视觉语义已验证，仍应核对描述与原图。

自定义 HTTP JSON 模式继续沿用现有端点、认证和响应字段路径，但陪读响应需要是 JSON 对象（或该对象的 JSON 字符串）：

```json
{"content":"Markdown 回答", "tool_calls":[]}
```

工具请求示例：

```json
{"content":"", "tool_calls":[{"id":"call_1","function":{"name":"read_material","arguments":{"page":1}}}]}
```

自定义模板增加 `{{messages}}`、`{{images}}`、`{{tools}}`。完整字符串占位符替换为结构化数组，嵌在字符串里的占位符则序列化为 JSON。示例：

```json
{"model":"{{model}}", "messages":"{{messages}}", "tools":"{{tools}}", "images":"{{images}}"}
```

这些字段必须适配服务商实际协议，不能保证任意自定义接口直接接受。文字模式仍支持 `{{prompt}}`；发送图片时模板必须有 `{{images}}` 或 `{{messages}}`。原翻译调用及原有模板行为没有改变。

## 数据与接口

前缀 `/api/documents/{doc_id}/reading`：

| 接口 | 行为 |
| --- | --- |
| GET / POST | 读取／创建当前会话；创建本身不调用模型 |
| PATCH | 带 `revision` 更新阅读单元、路线、深度、状态或浏览页 |
| DELETE | 归档会话、取消任务；迟到回答不能写回 |
| POST /messages | 提交带 `revision`、模型配置、动作及可选选区的后台任务 |
| DELETE /messages/{id} | 带 `revision` 删除一条提问和回答，清理派生记忆与关联任务 |
| DELETE /messages | 带 `revision` 清空对话，停止任务并拦截迟到回答 |
| GET / POST /notes | 列出本篇论文笔记，或仅提交 `message_id` 收藏服务端完整回答 |
| GET / DELETE /notes/{id} | 查看或删除笔记 |
| GET /notes/{id}/download | 导出含公式、引用原文、来源页码和图像区域说明的 Markdown |
| GET /notes/{id}/images/{source_id} | 使用笔记独立保存的来源渲染原文区域 |
| GET /jobs/{id} | 查询任务阶段、工具记录和错误 |
| DELETE /jobs/{id} | 取消任务 |
| GET /images/{source_id} | 渲染当前会话实际取得过的原文区域 |
| GET /summaries/{id} | 下载当前会话的小结 |
| GET /text/{page} | 读取原文规范字符、行方向和归一化坐标，文字层独立版本 |
| POST /citations | 按文字层版本及字符范围在服务端重建引用；不接受客户端文字作为依据 |

消息请求支持 `mode_id`（`quickread`、`guided`、`detail`、`followup`、`citation`）和 `citations`（最多12条页面引用，每条包含 `page`、`text_version`、`ranges[{run_id,start,end}]`，字符位置按 Unicode 码点计数）。显式引用兼容旧 `followup` 请求，旧版会话的引用问答通过应用适配层读取新规则。引用结果增加 `block_ids` 和可选的 `context_ambiguous`，映射不完整或重叠时标明定位需核对，并补充原文及对应版本译文页面。回答保存 `context_sources`、`context_map`、`visual_sources` 和来源快照。速读与引用工作流使用当前应用规则并记录版本，其他工作流沿用已存快照。模型输出不合规时仅修复一次，仍不合规则失败，保留旧回答。

文字层使用 PDF 原始字符映射，不按论文名称或固定页码分支；服务端保留连字、软连字符等原始 Unicode，页面引用可独立于段落定位。无法可靠映射的编码或几何保留原图并提示框选。页面文字层按可见页与邻页加载，后端只保留32页内存缓存，不修改原 PDF 或排版缓存。

`reading.json` 版本为 1，独立于译文和排版缓存。所有写接口沿用本机来源和 `X-Local-Token` 校验。资源工具只读固定快照的 `references/`；模型不能调用任意 Shell、访问其他论文或自行指定保存路径。

收藏笔记存放在同一论文目录的 `reading-notes.json`，版本为1，使用锁和临时文件替换实现原子写入。笔记来源独立于对话，收藏接口从服务端读取回答并生成稳定收藏ID。旧 `reading-notes/*.md` 小结按原ID兼容读取；删除旧小结时先保存快照，再清理文件和记录，失败可重试。笔记存储读取失败会报告错误并保留原文件。

阅读器默认双击选词；编辑译文默认关闭，在菜单开启「译文编辑」后可双击译文段落编辑，未开启时 PDF 与段落视图都不显示编辑入口。选中原文或译文后可用「解释」「引用」「高亮」；引用卡片显示在 AI 助读输入框内，并自动聚焦输入框。右侧保留「笔记」并新增「批注」标签，汇总当前文档的本地高亮、待发送引用和对话引用，支持点击回跳与删除高亮。段落视图的灰色原文预览按原文引用，不再因存在译文而被标为译文。

速读一次提供完整原文及全部页面图，引用问答完整提供选定上下文；两者采用四轮、每轮最多12项补读或区域查看的协议。其他阅读模式维持12次工具预算和每次最多10,000字符的游标读取。上下文检索返回原始完整段落，图像来源记录区域、原文或译文版本及渲染倍率。每轮图像合计设有 64 MiB 本机容量限制，超过时提示按章节或选区阅读。完整论文材料超出接口容量时可调整模型后重试。相同图像在本轮复用，旧回答的来源状态使用独立快照，便于后续收藏和复核。引用问答的近期对话辅助理解追问，速读使用本轮完整论文材料建立整体分析。

第一版不执行外部搜索、不提供完整 OCR、完整笔记编辑或多论文综述。图像模糊、模型不支持视觉、无文字层或标题不可靠时须明确提示，不视为已完成适配。

## 验证

主项目于 2026-11-06 整合贡献提交，具体回归数量和样本边界见 [更新日志](../CHANGELOG.md)。

- 合成测试覆盖单栏、双栏、不同页面尺寸和四种旋转，以及图表、公式、作者信息、字体、段间距和参考文献。助读测试涵盖全文与全部页面图、工具预算、图像去重、容量错误、取消、引用版本和清空后的独立笔记来源。
- Edge 浏览器验收使用临时数据和模拟模型，覆盖真实鼠标拖选、原文及译文引用、编辑、多色高亮、笔记恢复和导出、公式及表格、HTML 清理，以及 700—1920 像素窗口。
- 本机 10 篇真实论文的隔离副本共 146 页，检查了目录、阅读单元、原文字符层、引用文字和区域图像，另检查 10 页已有译文。实际样本含三种页面尺寸、双栏和跨栏宽文本，旋转均为 0 度。27 页出现局部编码警告。抽取的引用中，1 条原文引用及 7 条译文引用的段落映射存在歧义，需要结合页面图核对。
- 模拟接口验证取材和执行流程。真实模型的理解质量、引用语义及格式遵循仍需评估。局部回退和定位歧义仍存在，有限样本的流程检查不能代表所有论文均已适配。

运行自动回归时使用项目虚拟环境。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test (Get-ChildItem tests/test_*.js).FullName
```

可选浏览器验收依赖 Playwright 和本机 Microsoft Edge，执行 `python tests/browser_reading_smoke.py`。测试使用临时文档及导出目录、独立端口和模拟模型，截图写入被 Git 忽略的 `tmp/`。
