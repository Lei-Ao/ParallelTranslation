# 论文助手：概览、导航、精读与问答

本文记录原分析功能，现保留在「历史分析」入口。新默认入口为直接加载 Skill 的连续陪读，包含工具调用、视觉和小结，见 [Skill 原生陪读说明](skill-reading.zh-CN.md)。

## 已交付范围

第一阶段包括直接阅读、原生书签／自动识别目录、结构化概览及来源定位。第二阶段包括段落解释与总结、当前论文问答、历史恢复和清空。两阶段共用现有模型配置和双栏阅读器。笔记、卡片、多论文比较、MinerU、OCR 和视觉识图不在本轮范围。

`paper_analysis.py` 负责结构识别、来源校验、任务调度、缓存及本地检索。主项目的 PDF 排版缓存版本为 67，助读记录独立存储。

## 接口与数据

所有接口位于 `/api/documents/{doc_id}` 下，沿用本机访问限制和写请求的 `X-Local-Token` 校验。

| 方法与路径 | 行为 |
| --- | --- |
| `GET /outline` | 读取目录，不调用模型；依次选择原生书签、基于版式的标题候选、页码导航 |
| `GET /analysis` | 读取概览、精读结果、任务及问答历史；将服务重启前遗留的运行任务标为中断 |
| `POST /analysis/config` | 校验结果的配置和内容指纹，不调用模型，不保存密钥 |
| `POST /analysis/jobs` | 创建理解任务或返回缓存／已在运行的同类任务 |
| `GET /analysis/jobs/{job_id}` | 读取单个任务进度及成功结果或错误 |
| `DELETE /analysis/conversation` | 清空当前论文对话及相关任务记录，使迟到回答失效 |

任务请求继承翻译请求的 `agent`、`target`、`instructions`、`glossary`；新增 `kind`（`overview`、`explain`、`summary`、`question`）、可选 `block_id`、`question`、`scope`（`document`／`selection`）及 `force`。解释、总结和所选段落问答必须提供有效段落。翻译继续使用原有接口。

来源统一为 `{doc_id, page, block_id?}`，页码从 1 开始。模型只提交所给上下文中的段落 ID，服务端补充文档和页码；对伪造、越界或未提供给模型的引用整条拒绝，旧结果保留。无依据内容使用 `missing`，不能冒充有来源的论文陈述。原生目录也可使用页码与页面比例位置，不要求改写段落。

`analysis.json` 使用独立版本 `1`，包含结果、成功分块缓存、任务和会话；加锁并使用临时文件替换实现原子保存，不参与 `document.json` 的译文写入。配置指纹覆盖模型接口设置、语言、要求、术语和提示词版本；不包含密钥和网络超时时间。保存来源文本及已有译文的内容指纹用于识别过期结果。

## 任务与失败行为

- 概览按最多 14,000 字符的源文本分块，过长的单个文本块按同一稳定 ID 分片，不截断剩余文本；全部成功分块进入分层汇总。汇总不能继续压缩时明确失败，不偷偷丢弃内容。
- 分块失败记录页码和原因；成功分块持久化，下次普通重试复用。强制重新生成重新请求各分块。无文字页仍报告为未解析，重复点击不会因此无限重算。
- 每篇论文至多一个概览和一个问答任务同时执行，总计最多三个理解任务；进程最多十二个理解任务。后台任务在页面刷新后继续，服务关闭先取消任务再关闭 HTTP 客户端。
- 当前论文问答使用词频与稀有词权重排序，最多选八个匹配段落并补充相邻段落，原文预算 24,000 字符；使用已存译文和通用中英学术词扩展改善匹配。无匹配时直接报告依据不足，不调用模型生成空泛回答。
- 所选段落及邻接上下文超过预算时优先保留完整所选段落；单段超过 30,000 字符则明确拒绝精读，不截断原文。最近三轮对话仅辅助理解追问，每轮重新检索原文作为依据。
- 清空会话递增本地代次；正在返回的旧回答不能重建已清空的历史。切换文档／段落时前端检查所属对象，防止异步响应串写面板。
- 不在新文件保存 API 密钥或原始异常堆栈；未知错误使用固定错误提示。模型文字仅按普通文本渲染，不执行模型返回的 HTML。

## 贡献分支的验证记录与限制（2026-11-05）

以下记录来自贡献者。主项目的集成验证见 [更新日志](../CHANGELOG.md)。

- 新增后端回归涵盖目录识别、来源校验、内容不变、缓存及配置更新、无文字页、长文无损分块与多级汇总、部分失败重试、任务去重、并发修订保存、会话清空及跨文档隔离。
- 合成 PDF 覆盖单栏／双栏、612／720 点页宽、0／90／180／270 度旋转、原生目录及无目录文档；现有版式测试继续覆盖图表、公式、标题、作者信息、字体与段间距。
- 命名书签使用 PDF 原生坐标时，先转换到页面坐标再处理旋转；四种旋转均有命名书签回归。实际核对 8 页论文的方法章节跳转，标题与目标位置一致。
- 本地论文只读目录检查覆盖两篇论文的三份存档共 36 页：14 页论文的两份存档各识别 34 个原生书签，8 页论文识别 36 个书签。原始 PDF 和文档数据的 SHA-256 检查保持不变。这些真实样本以双栏版式为主，单栏及旋转覆盖来自合成样本。
- 浏览器验收使用隔离数据目录及模拟模型，无真实模型调用费用；检查直接阅读、概览来源双向定位、精读切换、问答与刷新恢复、宽屏侧栏和窄屏抽屉。
- 完整回归通过：211 项 Python 测试、64 项 JavaScript 测试；浏览器控制台未发现错误。
- 模拟模型验证接口、流程和来源约束，**未验证真实模型的概览质量、引用语义或解释正确性**。自动目录可能漏检或误识别；词法检索不能保证召回语义近似段落；有效来源 ID 不保证陈述受原文支持。扫描件、图片和缺失公式仍不受支持，不将本次样本检查视为所有论文均已适配。

运行回归：`python -m unittest discover -s tests -p "test_*.py"` 和 `node --test tests/test_*.js`。使用项目虚拟环境运行 Python。
